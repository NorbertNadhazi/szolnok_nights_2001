# Szolnok Nights 2001

A just-for-fun project and a memory of summer 2001.
Very early prototype (v0.1) – rough edges included.

Cruise the streets of Szolnok at night in a German sports coupé,
an East German two-stroke twin or a Soviet four-stroke sedan,
with your own music on the CD player. Handbrake turns, burnouts,
honking at the crew, and cheeky games of cat and mouse with the cops.
